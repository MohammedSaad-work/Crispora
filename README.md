# Crispora

A static restaurant website concept built with HTML, Bootstrap, custom CSS, and local food imagery.

## What it includes

- A restaurant-style landing page with navigation and visual sections
- Menu and food imagery stored in `img/`
- Responsive layout rules and Bootstrap components

The repository contains a local Bootstrap distribution as well as a Bootstrap CDN reference in the page. The current page should be checked for which local assets it actually uses before removing either copy.

## Run locally

Open `index.html` in a browser. An internet connection is needed for assets referenced from external CDNs. Keep the `img/` directory beside the page.

## Technologies

- HTML
- CSS, including styles in `index.html`
- Bootstrap 5
- Static image assets

## Project status

This is a front-end concept. No ordering, payment, or backend service is included.
